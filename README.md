# Enter в FAST Input: эмуляция неявной отправки формы

Интерактивное демо: как FAST-компонент `Input` повторяет поведение браузера при нажатии Enter в форме (HTML Standard, §4.10.22.2 «Implicit submission»).

**Демо:** https://tonyxdddd.github.io/FAST-test/

## Что внутри

- **Цепочка по этапам:** что происходит от `keydown` до `submit`, с кодом каждого шага.
- **20 живых кейсов:** какую кнопку нажать, подсчёт полей, disabled и `<fieldset disabled>`, скрытые кнопки, `form="id"`, отмена через `preventDefault`, валидация, FAST-обработчик без `return true`, пикер с открытым попапом, Shift/Ctrl+Enter.
- **Журнал шагов у каждого кейса:** события браузера, методы компонента и шаги алгоритма, с отметкой времени от `keydown` и итогом ✔/✘.

Кликните в поле и нажмите настоящий Enter. Кнопка «Симулировать» отправляет синтетические `keydown` → `keypress`, но нативного `change` при этом нет.

## Файлы

| Файл | Что делает |
|---|---|
| `index.html` | текст по этапам и контейнер для кейсов |
| `explain.css` | стили, светлая и тёмная тема |
| `explain-impl.js` | алгоритм (`mimicFormEnterBehavior`, `handleFormEnterKeypress`) с журналом шагов и тестовые FAST-компоненты |
| `explain-cases-a.js`, `explain-cases-b.js` | описания кейсов |
| `explain-app.js` | отрисовка карточек и кнопки управления |

`@microsoft/fast-element` 2.10.5 загружается с CDN jsdelivr, сборка не нужна.

## Локальный запуск

ES-модули не работают при открытии через `file://`, поэтому нужен любой статический сервер:

```bash
python -m http.server 8765
```

После запуска откройте http://localhost:8765/.
