Кастомные компоненты в форме

  • Как отличить кастомный элемент. FAST-компоненты наследуются от HTMLElement, а не от HTMLInputElement. Признак «не input и не textarea» не подходит: в form.elements есть ещё нативные button, select, fieldset и output (кейс 24). Надёжный признак — дефис в имени тега.
  • Поле или нет — решает type. Сначала проверяем первый Set (типы нативных полей: text, number, date…). Если там нет — второй, customSubmitBlockingElementTypes, с нашими уникальными типами: date-interval, time-interval, year (кейс 21).
  • Не считаются компоненты без type или с типом, которого нет ни в одном Set (кейс 22).
  • Кнопка отправки — кастомный элемент с type="submit".

Новый компонент с уникальным типом нужно добавить во второй Set. Интервал — один элемент, поэтому он считается одним полем (кейс 23).

Зачем эмулировать

  • Внутренний <input> лежит в shadow DOM компонента. Форма определяется только в пределах одного DOM-дерева, поэтому с внешней формой он не связан и сам её не отправит.
  • С формой связан хост: static formAssociated = true и attachInternals(). Но неявная отправка в этот механизм не входит: браузер по Enter смотрит только на нативные элементы.
  • Поэтому Input сам повторяет алгоритм из спецификации HTML (§4.10.22.2) и учитывает всех соседей в форме — нативных и кастомных.

Цепочка по этапам

  1. браузер keydown → handleKeydownEvent

    Браузер присылает keydown на внутренний input. Биндинг @keydown в шаблоне вызывает handleKeydownEvent. Остальные клавиши сразу получают return true, и FAST их не трогает.

  2. компонент Enter → mimicFormSubmitBehavior

    Для Enter эмуляция запускается сразу, прямо во время keydown. Возвращаемое значение переворачивается: return !mimicFormSubmitBehavior(this.elementInternals).

  3. шаг 1 есть ли форма

    Берётся elementInternals.form. Если формы нет — return false (кейс 19). Атрибут form="id" на самом компоненте тоже работает: это делает ElementInternals.

  4. шаг 2 кнопка по умолчанию

    Это первая submit-кнопка в form.elements: по порядку документа, включая элементы вне формы с form="id" (кейсы 6, 7). Submit-кнопками считаются:

    • <button> без type или с type="submit";
    • input[type=submit|image];
    • кастомный элемент с type="submit".

    Отмеченный checkbox кнопкой не считается (кейс 11). input[type=image] ищется отдельно, в form.elements его нет.

  5. шаг 3 кнопка нашлась → return true

    Неактивная кнопка (:disabled, в том числе через <fieldset disabled>) не нажимается, и следующая не ищется (кейсы 8, 9). Активная нажимается через button.click(), видимость роли не играет (кейс 10). В обоих случаях функция возвращает true.

  6. браузер после click()

    click() ведёт себя как клик мышью: событие всплывает и его можно отменить (кейс 13). Нативная кнопка запускает проверку формы: при ошибке — invalid, отправки нет (кейс 16). Если ошибок нет — событие submit. Наша кнопка в обработчике клика вызывает form.requestSubmit(), дальше то же самое.

  7. шаги 4–5 кнопок нет: подсчёт полей

    Считаются нативные input 12 текстовых типов и кастомные элементы, у которых type есть в первом или втором Set (подробнее — во врезке вверху). Checkbox, select, textarea и hidden не считаются. Меньше двух полей — form.requestSubmit() и return true (кейсы 2, 5, 12, 22). Иначе return false (кейсы 3, 4, 17, 21).

  8. компонент return !handled → FAST

    Если FAST-обработчик вернул не true, FAST сам вызывает preventDefault(). Поэтому true от mimicFormSubmitBehavior превращается в false и отменяет keydown. false превращается в true, и keydown остаётся как есть.

  9. браузер последствия отмены keydown

    Если keydown отменён, браузер не присылает keypress, а нативный change по Enter не срабатывает. Он придёт позже, при потере фокуса (кейс 1). Если не отменён — приходят keypress и change (кейсы 17, 19).

  10. браузер порядок обработчиков

    Обработчик висит на внутреннем input, поэтому срабатывает раньше обработчиков на форме и документе. Отменить отправку через preventDefault() на форме уже нельзя (кейс 14). Перехватить Enter можно только в capture-фазе через stopPropagation() (кейс 15).
